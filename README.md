# Привычка · English B1–B2

[Открыть приложение](https://evgk724.github.io/used-to-lab/)

Пять коротких уроков о `used to`, `would`, `be used to`, `get used to` и их различиях. 64 задания: воспроизведение, выбор, исправление и слушание. Объяснения на русском; авторские примеры B1–B2. Материал подготовлен по темам предоставленных пользователем фотографий и сверен с источниками, указанными в приложении. Исходные фотографии не публикуются.

Полные английские образцы озвучены Microsoft `en-GB-RyanNeural`. Приложение использует готовые MP3, без замены на системный голос. После надписи «Готово офлайн» весь набор доступен без сети, включая ещё не прослушанные записи. В Safari: «Поделиться» → «На экран Домой».

Ответы изначально скрыты. Самооценка влияет на повторения: трудность возвращает задание раньше; успешное воспроизведение увеличивает интервал до 1, 3, 7, 14 дней. Это практический ориентир, не измерение знаний. Прогресс хранится в localStorage только в этом браузере. Синхронизации и аккаунтов нет.

## Разработка

Статическое приложение без сборщика и клиентских зависимостей. `python3 -m http.server 8765` для локального запуска. `node --test tools/test-engine.mjs` проверяет расписание, очередь и соответствие контента записям. `python tools/audio.py --check` проверяет готовое аудио. Генерация использует edge-tts и стандартное TLS-соединение. После изменения клиентских файлов меняйте имя кеша в sw.js. GitHub Actions проверяет материал перед развёртыванием Pages.
